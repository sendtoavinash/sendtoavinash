# 💫 About Me:
Senior Software Engineer with 6+ years of experience designing, building, and operating scalable backend platforms across telecom, gov-tech, and enterprise domains. Specialized in Java (8–17), Spring Boot (2.x/3.x), and event-driven microservices, with hands-on ownership of systems sized for 1M+ daily transactions and validated throughput of 500K+ events per day in production. Strong track record of improving performance and reliability, including cutting API response times by 30%, reducing database load with Redis caching, and improving uptime and deployment speed through resilient architectures and CI/CD automation.<br>Skilled in Kafka, WebFlux, PostgreSQL, Redis, RabbitMQ, and Salesforce/Mulesoft integrations, with experience building secure, fault-tolerant flows using Spring Security, OAuth2, JWT, and OWASP-aligned practices. Comfortable driving end-to-end delivery: high/low-level design, API contracts, observability (Splunk, ELK, Grafana, Prometheus, tracing with Sleuth/Zipkin), and production incident resolution within strict SLAs.<br>Increasingly focused on GenAI integration, including LLM-backed services, summarization APIs, and schema-validated JSON outputs, backed by real implementations like `llm-summarizer` and `petcare-streams` in production-like setups. Certified in AWS and IT Architecture, and experienced with Docker, Kubernetes, Jenkins, and GCP, delivering secure, scalable solutions in Agile teams while mentoring, reviewing code, and setting patterns through reusable templates such as `sb3x-microservice-template` and `kafka-event-pipeline` on GitHub.
